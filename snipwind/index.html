Output you would write yourself

Most copy tools dump every computed style. Snipwind keeps only what the element needs.

Three formats

Tailwind classes, plain HTML with a small stylesheet, or a JSX component. Switch tabs, copy the one you need.

Stays flexible

Widths that were auto, percentages and calc() stay that way, so the copy still adapts to its container.

No defaults, no noise

Styles the browser or Tailwind already applies are left out. Padding, borders and corners collapse into shorthands.

Icons and details

Inline SVG icons come along with their colours, and so do ::before and ::after decorations.

Tailwind v3 and v4

Only uses class names that mean the same thing in both versions, with exact values where they differ.

Private by design

Everything runs inside the page you are on. No account, no tracking, no page content sent anywhere.

How it works

Three steps, no setup.

Start picking

Click the Snipwind icon in the toolbar, or press Alt + Shift + C.

Click an element

Hover to highlight, click to select. ↑ moves to the parent, ↓ to the first child.

Copy and paste

Choose Tailwind, HTML + CSS or JSX, press Copy, and paste it into your editor.

FAQ

Is it free?

Yes. Snipwind is free to use.

Does it copy fonts?

It copies the font names and sizes, not the font files. If your project does not load the same web font, text falls back to the next font in the list.

Does it copy hover effects and mobile layouts?

Not yet. Snipwind copies the element as it looks at the moment you click it.

Is my browsing data collected?

No. The extension only runs when you click its icon, works entirely inside that page, and has no analytics. See the privacy policy.

Can I use what I copy?

Snipwind copies structure and styling. Text, images, logos and overall designs still belong to their owners, so use it to learn from and adapt layouts, not to clone someone's site.
